# Miniproject 1

## Naming standard
 
### Schemas

Since we are using simple enough databases we should use the generic dbo. as a schema.
 
### Operational Database

We'll use snake case as a naming standard since it's more commonly used "out in the wild".
 
Table names		= Customer, OrderLines, AnimalSpecies

Column names	= first_name, personal_id, address_line_1

Private Keys	= customer_pk, order_lines_pk, animal_species_pk
 
 
### Data Warehouse

Prefixes - Fact and Dim tables - ie FactSales, FactIncidentReport. DimCustomer, DimLocation
